# Between Two Homes — eBook companion

This folder will host the printable, digitally fillable PDF companion to the Kindle edition.

## Upload on this branch

Upload the reviewed file `Between_Two_Homes_Complete_Fillable_Workbook_Checkboxes.pdf` to this folder using GitHub's **Add file → Upload files** control, making sure the selected branch is `between-two-homes-ebook`, not `main`.

The companion PDF contains interactive text fields and checkboxes. Test the hosted file in Adobe Acrobat Reader before linking from the Kindle eBook or merging into `main`.

Do not modify the existing PHP checkout/download files. A public GitHub Pages link will be added only after the PDF is uploaded and its URL is verified.
